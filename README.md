# Bi-Lipschitz Factor Flows

PyTorch implementation accompanying **[Bi-Lipschitz Factor Flows:
Regularizing the Latent Geometry of Flow-Matching Decoders](Paper.pdf)**,
accepted at the **PriGM workshop at NeurIPS 2026**.

This repository contains the core model, geometric regularizers,
training code and illustrative configurations.
See the paper for the method, theoretical analysis and experimental results.

The configurations are not intended to reproduce the reported numbers exactly.
